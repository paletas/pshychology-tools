## 4. Day-count age versus calendar age

Kept as-is, needs confirmation. The old app computes the age as a day count added to 0001-01-01 (not the calendar difference), and the new app does the same. ## 5. Index sums that are not in the conversion tables

Kept as-is, needs confirmation.

The old app finds an index (IQ, percentile, CI) only for sums that exist as keys in its tables. Two situations were checked:

- Sums inside the table range that are not keys (gaps): none found in any index.
- Sums outside the table range (below the lowest key or above the highest): the old app silently showed another row (for example the verbal sum 0 gives IQ 155, percentile 100). The new app shows these cells as unavailable (a dash, with the hint "Soma fora da tabela de conversão") and draws no classification arrow or chart value for that index. Please confirm that "unavailable" is the right behaviour.

## 6. Processing Speed index from Coding alone (Symbol Search omitted)

Kept as-is, needs confirmation. When the optional Symbol Search test is omitted, the Processing Speed sum is made from Coding alone and an index is still shown when that sum exists in the table. This happened in 2197 of 10000 simulated cases (22.0%); examples (simulated case ids): s00005, s00012, s00019. Decision for now: kept; to be validated with the psychologist.

## 7. Age-gate leak (fixed)

Deliberately changed, needs confirmation. The supported age range is 6y 0m 0d up to (not including) 17y 0m 0d. The old gate leaked at both edges: 62 ages below 6 years (5y 10m 0d to 5y 11m 30d) were scored with the 6y 6m band, and 93 ages from 17y 0m 0d to 17y 2m 30d passed the gate (93 of them crash the old app). The new app blocks all of them like any other unsupported age. Please confirm that the strict range is wanted.

## 8. Percentile number format follows the browser locale

Kept as-is, needs confirmation. The old app writes percentiles with the browser's decimal separator (for example "0,5" with a Portuguese browser, "0.5" with an English one). The new app does the same. Please confirm that this is acceptable on printed or pasted results.
